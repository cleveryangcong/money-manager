# Money

A small, ad-free expense tracker that runs as a Home Screen web app (PWA).
All data stays on the device in browser storage — nothing is sent anywhere.

- Overview with donut chart (day / week / month / year / custom period)
- Transactions, categories with monthly budgets, regular payments
- Backup / restore as JSON, CSV export

Install on iPhone: open the site, tap Share → **Add to Home Screen**.
